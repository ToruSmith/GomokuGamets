## 安裝到手機或電腦

安裝後會出現在主畫面，打開時沒有網址列；第一次載入完成後，**沒有網路也能玩**（線上對戰除外）。

| 裝置                 | 做法                                                              |
| -------------------- | ----------------------------------------------------------------- |
| iPhone／iPad         | 用 Safari 打開網址 → 點「分享」→「加入主畫面」                    |
| Android              | 用 Chrome 打開網址 → 右上角選單 →「安裝應用程式」或「加到主畫面」 |
| 電腦（Chrome、Edge） | 網址列右側的「安裝」圖示                                          |

## 遊戲模式

| 模式       | 內容                                                                 |
| ---------- | -------------------------------------------------------------------- |
| 和電腦下   | 入門、初級、中級、高級、高手五段，可以選執黑或執白，能悔棋、要提示。 |
| 兩人同機   | 同一台裝置輪流下。                                                   |
| 線上對戰   | 開房間，把連結傳給朋友。見[和朋友線上對戰](#和朋友線上對戰)。        |
| 殘局題     | 14 題，用連續衝四在限定手數內取勝。每一題都經過程式驗證有解。        |
| 棋譜與戰績 | 看回過去的對局、各難度的戰績，也能匯入棋譜。                         |

- 棋盤有 13、15、19 路三種（連珠固定 15 路）。
- 和電腦下與兩人同機可以設定每方限時 5 或 10 分鐘，時間用完就輸。
- 下到一半關掉也沒關係，首頁會出現「繼續上一盤」。

## 三種規則

**自由**：橫、直、斜任一方向連成五子或更多就贏。最適合初學者。

**標準**：必須**剛好**連成五子才贏，連成六子以上（長連）不算。

**連珠**：正式比賽使用的規則。黑棋先下比較有利，所以黑棋有「禁手」，不能下在下列位置（遊戲會擋下並說明原因）：

- **雙三**：一手棋同時做出兩個活三。
- **雙四**：一手棋同時做出兩個四。
- **長連**：連成六子以上。

例外是**成五優先**：如果這一手剛好連成五子，即使同時形成禁手也算黑棋贏。白棋沒有禁手，長連也算贏。
選連珠規則時，棋盤會標出黑棋目前的禁手點。

## 和朋友線上對戰

1. 點「線上對戰」，輸入暱稱（1～16 個字）。
2. 選規則與限時，按「開新房間」。
3. 把畫面上的連結或 6 碼房號傳給朋友，朋友打開連結（或輸入房號）就會入座。
4. 開房的人選執黑或執白，黑棋先下。

對局中：

- **斷線或重新整理**：用同一台裝置、同一個瀏覽器回到原本的連結，就會回到同一盤棋。
- **限時對局**：時間由伺服器記錄，黑棋第一手不計時。時間用完的一方輸。
- **認輸、再戰**：結束後可以「再戰一局」，雙方交換黑白。
- **表情**：可以傳送預設的表情，沒有文字聊天。
- **觀戰**：兩個座位都坐滿後，第三個人打開連結會變成觀戰。

線上對戰需要網路，沒有網路時其他模式照常可以玩。

## 復盤與賽後分析

- 對局結束後可以拖曳時間軸逐手看，或自動播放；也能「從這裡接著下」，試試別的下法。
- 「分析這盤棋」會讓 AI 看完每一手，畫出黑方勝率曲線，標出緩手、失誤與錯過的勝機，並顯示 AI 建議的位置。
- 可以複製棋譜連結傳給別人，或把盤面存成圖片。
- 在「棋譜與戰績」按「匯入棋譜」，貼上棋譜連結或像 `H8 I9 G7` 這樣的座標，就能打開別人的棋局。

## 操作小技巧

- **手機點兩下才落子**：第一下預覽位置，第二下確認，避免誤觸。可以在「設定」關閉。
- **鍵盤**：方向鍵移動，Enter 或空白鍵落子，U 悔棋，H 提示。
- **外觀**：設定裡可以換榧木、檜木、墨色、青瓷四種棋盤，以及淺色或深色主題；也能切換英文。
- 支援讀屏軟體與「減少動態效果」。

## 常見問題

**線上對戰一直連不上？**
先確認網路正常，再重新整理頁面。學校或公司網路有時會擋住即時連線，換成手機網路試試看。

**為什麼看到的還是舊版本？**
遊戲會先用裝置上的快取，讓沒有網路時也能開。新版本會在下一次開啟時生效，把分頁或 App 完全關掉再開一次即可。

**對手斷線了怎麼辦？**
棋局會保留，等對方回到同一個連結就能接著下。限時對局的時間會繼續走。

**戰績和棋譜不見了？**
這些資料只存在這台裝置的瀏覽器裡。清除瀏覽資料、使用私密瀏覽，或換一台裝置，都看不到原本的紀錄。

**電腦太強或太弱？**
五段難度差很多，可以從「入門」開始，贏了再往上調。下不過時試試提示，或在賽後分析看 AI 建議。

## 你的資料

- **不需要帳號**。遊戲不收集姓名、電子郵件，也沒有廣告或追蹤程式。
- **線上對戰**時，會用 Firebase 匿名登入取得一組隨機代號，房間裡存的是：暱稱、這組代號、棋步與時間、是否在線、表情與再戰的意願。
  任何拿到房號的人都看得到這些內容，所以暱稱不要用真實姓名。
  還沒開始的房間在你離開時就會刪除；其他房間超過一天後會被清除。
- **設定、戰績、對局紀錄與未下完的棋**只存在你的瀏覽器裡，不會上傳。
